🎯 Objetivo do Projeto
Este projeto tem como finalidade auxiliar traders iniciantes e avançados no planejamento financeiro de suas operações, oferecendo uma calculadora de metas e ferramentas de acompanhamento de evolução da banca. 

💡 Solução Proposta
Muitos traders iniciantes enfrentam dificuldades em manter disciplina e visualizar o progresso da banca ao longo do tempo.
Este projeto resolve esse problema ao fornecer:

Uma agenda automática de evolução financeira, que mostra passo a passo como atingir a meta.

Gráficos dinâmicos que permitem acompanhar a evolução da banca de forma visual e clara.

Exportação em Excel, para que o trader possa salvar e revisar seu plano fora da aplicação.

Links diretos para corretoras, facilitando o início das operações sem perder tempo.

Assim, o projeto ajuda a transformar o planejamento em uma rotina prática e organizada, reduzindo riscos e aumentando a disciplina.

🛠️ Tecnologias Utilizadas
HTML5 para estruturação da página

CSS3 para estilização e responsividade

JavaScript (ES6) para lógica e interatividade

Chart.js para geração de gráficos dinâmicos

XLSX.js para exportação de dados em planilhas
