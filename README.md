🎯 Objetivo do Projeto
Este projeto tem como finalidade auxiliar traders iniciantes e avançados no planejamento financeiro de suas operações, oferecendo uma calculadora de metas e ferramentas de acompanhamento de evolução da banca. 
🛠️ Tecnologias Utilizadas
HTML5 para estruturação da página

CSS3 para estilização e responsividade

JavaScript (ES6) para lógica e interatividade

Chart.js para geração de gráficos dinâmicos

XLSX.js para exportação de dados em planilhas

📂 Estrutura do Projeto
planejamento-financeiro-do-trader/
│
├── index.html          # Página principal
├── css/style.css       # Estilos e layout
├── js/script.js        # Lógica e interatividade
├── images/             # Logos e ícones
└── README.md           # Documentação do projeto

⚙️ Funcionalidades
Inserção da banca inicial, meta e prazo em dias

Geração automática de agenda de evolução financeira

Exportação da agenda em formato Excel

Visualização gráfica do progresso da banca

Links diretos para corretoras parceiras
